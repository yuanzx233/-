# 已知限制

1. 仅支持最大 50 MB 的标准 ASCII DXF；二进制 DXF、DWG、外部参照和复杂代理实体不在 MVP 范围。
2. 坡地只做二维等高线与高程点分析，入口、排水、挡墙和土方结论必须人工复核。
3. 歧义边界、非标准图层、重复/自交几何不能靠“人工知悉”直接放行，必须修正图纸后重新解析。
4. 平面方案来自已审核模板匹配和几何调正，不是施工图；结构、机电、消防、节能和报建合规未自动完成。
5. 效果图用于外观方向沟通，不能证明与平面、结构和真实材料完全一致；最终结果需人工抽检。
6. 三维输出目前是概念体块，不含屋面节点、构造层、结构构件和 BIM 信息。
7. 方案 HTML 是当前正式汇总格式；Day 1 的 PPTX/PDF 属于工具链概念包，不等同于完整 14 章方案文档。
8. 微信内置浏览器对 Blob 新窗口和下载行为存在版本差异，无法预览时应使用“生成并下载方案 HTML”。
9. 生产站点为私有演示环境，仅授权账户可访问。

## 发布前仍需人工完成

- iOS/Android 微信真机签字。
- 至少两套实际项目数据的效果图与锁定平面一致性抽检。
- 设计专业人员对演示项目风险提示和免责声明复核。
