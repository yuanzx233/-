# Day 10 发布验收清单

## 自动化发布门禁

- [x] 16 份代表性 DXF 全量解析：规则矩形、米制、旧式多段线、L 形、多面临路、梯形斜边、控制线、现状对象、坡地和歧义文件。
- [x] 异常 DXF：未闭合与多个地块必须返回明确错误；歧义文件必须阻断下游方案生成。
- [x] 大文件：50 MB 边界允许，超过 1 byte 拒绝；空文件、错误扩展名及错误 MIME 拒绝。
- [x] 任务重试：仅 FAILED/TIMED_OUT 可重试，最多 3 次；成功或运行中任务不可重试。
- [x] 版本关联：需求版本 → 锁定平面版本 → 风格版本 → 效果图任务/资源 → 方案报告。
- [x] 效果图：主入口、鸟瞰、庭院至少生成两张，资源保存提示参数、任务 ID 和输入版本 ID。
- [x] 文档：方案 HTML 固定 14 章，面积指标一致，图片保持比例，页面内置溢出检查。
- [x] 技术产物：PNG、OBJ、PPTX、PDF 均可重复生成且非空。

执行：

```powershell
pnpm test
```

## PPT/PDF 逐页抽检

当前概念包为 1 页 PPTX + 1 页 PDF。发布前逐页检查：

1. 标题、地块预览、面积、周长和免责声明完整。
2. 图片保持比例，无拉伸、裁切核心轮廓或低清晰度。
3. 文字不越界、不重叠，中文字体可读。
4. PPTX 与 PDF 的面积、周长与 `validation-report.json` 一致。
5. PDF 渲染后无黑块、缺字或分页异常。

## 微信真机检查

至少使用一台 iPhone 和一台 Android 微信内置浏览器：

- 登录、返回与重新进入状态正常。
- 375 px 宽度下无横向滚动；按钮触控区域不小于 44 px。
- DXF 选择、上传进度、失败重试和单位切换可操作。
- 场地预览可点击放大、关闭并下载 PNG。
- 户型需求数字键盘、下拉框和校验提示正常。
- 三套候选横向/纵向浏览正常，锁定后版本提示准确。
- 效果图画廊可加载、重试与选择最终图。
- 方案 HTML 可生成；微信不支持新窗口时使用下载入口。

真机结果需记录机型、微信版本、网络、结果和截图。当前自动化环境不能替代实体微信客户端，本项在正式对外发布前必须人工签字。

## 发布判定

- P0/P1 阻断问题为 0。
- 自动化测试与生产构建全部通过。
- 演示项目可从项目列表进入并完成报告生成。
- 真机检查已签字；若未签字，仅允许“内部演示”，不可标记为正式发布。
