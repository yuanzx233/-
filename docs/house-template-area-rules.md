# 自建房模板建筑面积与外墙轮廓判定规则

## 主体建筑面积

1. 建筑面积按主体建筑外墙最外侧连续围合线的水平投影面积计算，不采用轴线面积、房间净面积之和或外包矩形面积。
2. 外墙轮廓必须逐段依据 CAD `WALL` 图层的真实墙体位置识别；墙体存在内外两条边线时，取朝室外一侧的边线。
3. 凹口、退台和转折必须跟随实际外墙外侧线，不得用矩形补齐，也不得越过真实墙线形成凸出轮廓。
4. 门窗洞口造成外墙线暂时中断时，沿同一墙体外侧线连续补齐；门窗框、窗台线、开启线、门联窗构件线和墙体端头不得被误认为外墙轮廓。
5. 轮廓闭合后以多边形坐标计算面积，并用复核底图将计算边界叠加在原始墙线上核验。

## 庭院及附属空间

1. 露天天井、露天庭院不计入主体建筑面积，即使其被主体建筑局部或全部围合。
2. 庭院面积应单独记录，并在模板数据、校验报告和方案成果中明确标注为非主体建筑面积。
3. 门廊、雨棚、室外露台等附属空间按项目既定规则单独计算，不与主体建筑面积合并。

## 房间范围判定

1. 房间范围按房间一侧的墙体完成面逐段识别，以墙、门、窗所在墙线共同形成的实际闭合边界为准。
2. 门窗洞口处沿其所在墙体的房间侧边线连续补齐，不把门窗框、开启线或墙体厚度计入房间净范围。
3. 相邻房间必须分别沿共用墙两侧的完成面取界，不得用外包矩形跨越墙体或覆盖相邻房间。
4. 客厅、餐厅等开放连接空间按图纸实际空间关系处理；无实体墙时保留开放连接，并使用经建筑师确认的虚拟分界，不擅自补墙。
5. 厨房、卫生间、储藏室等独立围合空间必须从开放公共空间中扣除，不得因矩形估算而重叠。
6. 房间边界坐标形成闭合多边形后，应反算净面积，并与图纸房间面积标注逐间核对；不一致时必须回查墙线和开放分界。
7. 房间名称及面积标注放置在房间闭合范围的几何中心附近，并避免压盖墙、门、窗。

## 墙段断点与门窗处理

1. 先依据门窗块、门窗图层及其所在墙线识别合法洞口；合法门窗洞口必须保留，不得作为墙体断点补齐。
2. 除已确认的门窗洞口和开放空间连接外，其余墙段断点均按同一墙线、同一墙厚自动补齐。
3. 自动补齐不得跨越门窗范围，不得改变已确认的门窗位置、宽度、方向和开启关系。
4. 门联窗必须同时具有相邻门、窗构件及明确组合关系；不得仅凭相邻或墙线中断推断为门联窗。
5. 经建筑师确认“不存在门联窗”的模板，所有门窗对象的 `combinationId` 统一为空。
